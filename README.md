# Social Media Lead Filtering Simulation

This Python script simulates the challenge of monitoring social media for potential customer leads. It processes a list of sample mentions, classifying them into 'potential leads', 'false alarms', or 'noise' based on predefined keywords. The example highlights how automated tools can struggle with high false positive rates, mirroring the experience described in the accompanying article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
